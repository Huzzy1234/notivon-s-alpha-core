# VisaGuard Hub - Information & Overview

VisaGuard Hub is a comprehensive CRM and operations management system specifically designed for Visa and Travel Agencies (modeled after Lagos Visa Consultants).

## 🚀 Key Features

- **Multi-Step Intake Wizard**: A professional, user-friendly portal for applicants to submit personal and travel details.
- **AI-Powered Document Scanning**: 
  - **OCR Integration**: Uses `Tesseract.js` to automatically extract passport numbers and details from data pages.
  - **Tamper Detection**: Metadata analysis (`ExifReader`) to flag images edited with Photoshop or Canva.
  - **PDF Analysis**: `pdfjs-dist` integration for verifying financial markers in bank statements.
- **Pipeline Management**: A visual board for tracking applicants through stages: `Intake` -> `Document Review` -> `Ready for Submission` -> `Submitted` -> `Approved/Rejected`.
- **Advanced Dashboard**: Real-time stats, risk alerts, and visa type distribution charts (`Recharts`).
- **Calendar System**: Deadline tracking for travel dates and application milestones.
- **Audit Logs & Team Management**: Full tracking of agent activities and secure user roles.
- **Secure Document Management**: Automated missing document detection and verification badges.

## 🛠 Technical Stack

- **Frontend**: React 18, Vite, TypeScript.
- **Styling**: Tailwind CSS, Shadcn/UI (Radix UI).
- **Icons & Visuals**: Lucide React, Framer Motion.
- **State Management**: TanStack Query (React Query) & React Context.
- **Utilities**: `date-fns`, `zod`, `sonner`.
